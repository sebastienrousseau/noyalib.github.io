# The Sebastien Rousseau Open Source Rust Ecosystem

**noyalib** operates alongside a suite of production-grade open-source Rust libraries created by Sebastien Rousseau. Each library is built with strict memory safety guarantees, zero-dependency options, and high performance.

---

## 1. `dtt` (DateTime Library)
- **Official Website**: [dttlib.com](https://dttlib.com)
- **Documentation**: [Docs.rs/dtt](https://docs.rs/dtt)
- **Crates.io Package**: [crates.io/crates/dtt](https://crates.io/crates/dtt)
- **Source Repository**: [GitHub Repository](https://github.com/sebastienrousseau/dtt)
