# The Sebastien Rousseau Open Source Rust Ecosystem

**noyalib** operates alongside a suite of production-grade open-source Rust libraries created by Sebastien Rousseau. Each library is built with strict memory safety guarantees, zero-dependency options, and high performance.

---

## 1. `dtt` (DateTime Library)
- **Website**: [dttlib.com](https://dttlib.com)
- **Overview**: A comprehensive toolkit for parsing, validating, manipulating, and formatting dates and times in Rust.

## 2. `kyberlib` (Post-Quantum Cryptography)
- **Website**: [kyberlib.com](https://kyberlib.com)
- **Overview**: Implementation of NIST-standardized CRYSTALS-Kyber post-quantum key encapsulation mechanism (KEM).

## 3. `hsh` (Cryptographic Hashing)
- **Website**: [hshlib.com](https://hshlib.com)
- **Overview**: High-speed cryptographic and non-cryptographic hash primitives with zero unnecessary heap allocations.

## 4. `rlg` (Structured Logging)
- **Website**: [rustlogs.com](https://rustlogs.com)
- **Overview**: Zero-overhead structured logging framework for Rust applications supporting JSON and terminal output.

## 5. `vrd` (Random Number Generation)
- **Website**: [vrdlib.com](https://vrdlib.com)
- **Overview**: Fast, cryptographically secure pseudo-random number generator (CSPRNG) library.

## 6. `libmake` (Automated Crate Generator)
- **Overview**: Automated CLI generator for scaffolding standardized, high-quality Rust crate templates.
