Your YAML never leaves your machine. The library, the command line and the editor tools run locally, and the browser playground runs inside your tab. There is no noyalib-operated service that could receive a document.

Built to be handed untrusted input. No unsafe code, bounded nesting, alias budgets and size limits by default, and fuzzing and Miri on every change.
