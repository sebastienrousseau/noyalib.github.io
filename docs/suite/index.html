<div lang="en"><h1>noyalib Suite of Satellite Libraries</h1> <p>The <strong>noyalib</strong> ecosystem is designed as a set of synchronized satellite tools that deliver identical data parsing, validation, and serialization behaviors across every developer environment.</p> <h2>1. <code>noyalib</code> (Core Crate)</h2> <p>The core Rust library for data deserialization and serialization.</p> <ul> <li><strong>Features</strong>: SIMD SWAR acceleration, Rayon parallel multi-document streaming, Serde 0.9 compatibility shim, JSON Schema 2020-12 validation.</li> <li><strong>Installation</strong>: <code>cargo add noyalib --features simd,rayon</code></li> </ul> <h2>2. <code>noya-cli</code> (Command Line Utility)</h2> <p>High-performance terminal binary for data transformation.</p> <ul> <li><strong>Features</strong>: Querying, formatting, schema validation, streaming JSON/YAML conversion, and diagnostic benchmarking.</li> <li><strong>Installation</strong>: <code>cargo install noya-cli</code></li> </ul> <h2>3. <code>noyalib-wasm</code> (WebAssembly Runtime)</h2> <p>WebAssembly package optimized for browser and edge environments.</p> <ul> <li><strong>Features</strong>: Post-processed with <code>wasm-opt</code>, direct JS object conversion, zero native toolchain dependencies.</li> <li><strong>Installation</strong>: <code>npm install noyalib-wasm</code></li> </ul> <h2>4. <code>noyalib-mcp</code> (Model Context Protocol AI Server)</h2> <p>Native MCP server for AI models and LLM agent integration.</p> <ul> <li><strong>Features</strong>: Exposes <code>parse_yaml</code>, <code>validate_schema</code>, and <code>generate_schema</code> tools for Claude, GPT-4, and Antigravity agents.</li> <li><strong>Installation</strong>: <code>cargo install noyalib-mcp</code></li> </ul> <h2>5. <code>noyalib-lsp</code> (Language Server Protocol)</h2> <p>LSP server for code editors (VS Code, Neovim, Emacs, Zed).</p> <ul> <li><strong>Features</strong>: Real-time syntax diagnostics, schema hovers, autocompletion, and fault-tolerant <code>parse_lenient</code> error recovery.</li> <li><strong>Installation</strong>: <code>cargo install noyalib-lsp</code></li> </ul> </div>
