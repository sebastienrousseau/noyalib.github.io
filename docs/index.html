Core Architecture

Engineered for Modern Engineering

Every component in noyalib is crafted with safety, developer experience, and ultra-high performance in mind.

Zero-Copy SIMD Dispatch

Multi-byte SWAR, SSE2, and NEON vector scanning find structural delimiters in a single CPU pass with zero copy overhead.

<article class="feature-card">
  <div class="feature-icon-wrapper">SAFE</div>
  <h3>100% Safe Rust Guarantee</h3>
  <p>Enforces <code>#![forbid(unsafe_code)]</code> across the entire codebase. Guaranteed memory safety for untrusted user inputs.</p>
</article>

<article class="feature-card">
  <div class="feature-icon-wrapper">PAR</div>
  <h3>Parallel Rayon Streaming</h3>
  <p>Pre-scans multi-document boundaries and deserializes documents concurrently across all CPU cores.</p>
</article>

<article class="feature-card">
  <div class="feature-icon-wrapper">JSON</div>
  <h3>JSON Schema 2020-12</h3>
  <p>Automatic JSON Schema codegen via <code>schemars</code> and real-time schema validation via <code>jsonschema</code> engine.</p>
</article>

<article class="feature-card">
  <div class="feature-icon-wrapper">MCP</div>
  <h3>Model Context Protocol (MCP)</h3>
  <p>Native MCP AI server tool allowing LLM models (Claude, GPT-4, Antigravity) to query, parse, and validate data streams.</p>
</article>

<article class="feature-card">
  <div class="feature-icon-wrapper">LSP</div>
  <h3>IDE LSP &amp; Error Recovery</h3>
  <p>Fault-tolerant <code>parse_lenient</code> engine powers live diagnostics, schema hover docs, and completion in VS Code.</p>
</article>
