<div lang="en"><h1>Frequently Asked Questions (FAQ)</h1> <h3>What makes noyalib faster than legacy parsers?</h3> <p>noyalib uses SWAR/SIMD vectorization for scanning delimiters in a single CPU cycle, coupled with Rayon multi-core streaming for multi-document parsing.</p> <h3>Is noyalib compatible with serde_yaml 0.9?</h3> <p>Yes! Enable the <code>compat-serde-yaml</code> feature for a drop-in shim with zero migration friction.</p> <h3>Can noyalib run in WebAssembly / Browser environments?</h3> <p>Yes! The <code>noyalib-wasm</code> package provides WebAssembly bindings optimized for browser runtimes, Node.js, and Cloudflare Workers.</p> <h3>What is noyalib-mcp?</h3> <p><code>noyalib-mcp</code> is a Model Context Protocol (MCP) server that connects LLM tools (Claude, GPT-4, Antigravity) to noyalib's parsing and schema validation engine.</p> </div>
